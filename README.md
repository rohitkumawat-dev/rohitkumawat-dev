### 🌟 About Me
Hey there! I'm Rohit Kumawat, a passionate developer based in Mumbai, India, dedicated to building clean, high-performance web applications and interactive digital experiences. Guided by a relentless problem-solving mindset—or as I like to put it, `git commit -m "fix everything"`—I bridge the gap between intuitive front-end designs and robust back-end architectures to craft software that just works.

My engineering toolkit spans dynamic front-end frameworks like React, Next.js, and TypeScript, backed by powerful services using Python (FastAPI, Flask), Node.js, and Java. Whether I'm engineering real-time multiplayer type-racing games like TypeBaazi, building OCR-powered legal compliance scanners, or designing sleek custom web applications, I take pride in delivering well-structured, production-ready code. Beyond standard web development, I actively experiment with containerization via Docker, database optimization, and security tools on Kali Linux.
